LLM UNIFY

Help

From configuring models to connecting your applications.

Sign in

Sign in with the gateway’s master key. Operators set this key through the environment variable referenced by general_settings.master_key in the configuration file.

The key is used only while the page is open. Sign out on shared devices. Use HTTPS when accessing the gateway remotely.

Configure models

Edit model_list in the YAML loaded at startup, then restart the gateway. See deploy/proxy.yaml in the distribution for an example.

model_name is the name exposed to users; litellm_params.model identifies the upstream model. Set API keys through environment variables. After restarting, search and copy model names from the workspace.

“Configured” means a model is present in the configuration. Verify upstream availability and API support by sending actual requests.

Connect an application

  1. Copy the API Base URL from the workspace.
  2. Set it as the endpoint URL in a compatible client.
  3. Enter the master key in the API key field and a configured model name in the model field.

For HTTP requests, use Authorization: Bearer <master-key>. Chat Completions uses /v1/chat/completions; Responses uses /v1/responses. Choose an API supported by the upstream model.

Operational scope

The current console displays configuration. This version does not provide model editing, per-user virtual keys, usage summaries, or budget enforcement. Do not host users or tenants together if they cannot share a master key.

Full LiteLLM OSS compatibility is under development. Verify the APIs and upstream providers you need before deployment. The distribution’s README and docs/operations.md describe startup, upgrades, and rollback.
